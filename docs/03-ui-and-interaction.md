# 03 — UI 视觉体系与 1Password 交互规范

## 1. 视觉语言与设计系统

Keysmith 桌面端追求 **1Password 8 macOS 原生质感**：克制的灰度层级、高信息密度而不杂乱的三栏排版、细腻的微交互与清晰的键盘焦点指示。

### 1.1 主题与语义色板（Tailwind CSS v4 CSS Variables）

默认跟随系统（`prefers-color-scheme`），支持在设置中锁定浅色（Light）或深色（Dark）：

| 语义 Token | Light 模式参考 | Dark 模式参考 | 用途 |
| :--- | :--- | :--- | :--- |
| `--bg-sidebar` | `#EEF0F3`（配 macOS Vibrancy 半透明） | `#1A1D21`（配 Vibrancy） | 左侧导航栏底色 |

| `--bg-card` | `#F3F5F8` | `#2E333B` | 条目详情内的字段分组卡片 |
| `--border-subtle` | `rgba(0,0,0,0.08)` | `rgba(255,255,255,0.09)` | 栏位分割线与卡片描边 |

### 1.2 字体系统

* **界面正文字体**：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", sans-serif`
* **密钥/验证码/技术字段字体**：`"SF Mono", "JetBrains Mono", ui-monospace, monospace`，强制开启 `font-variant-numeric: tabular-nums`（保证数字等宽对齐，视觉一眼辨别 `0`/`O`、`1`/`l`/`I`）。

## 2. 1Password 标志性微交互详设

1. **三色密码高亮（Semantic Password Coloring）**
   * 明文显示密码时，逐字符渲染颜色：字母使用默认前景色，数字使用蓝色（`--pw-digit`），特殊符号使用橙红色（`--pw-symbol`），在视觉上瞬间区分复杂口令结构。
2. **大字展示（Large Type）**
   * 任何密码、PIN、API Secret 或 TOTP 字段悬浮栏点击放大镜图标（或选中条目按 `⌘L` 外的 `⌘⇧L` / `Space` 预览），弹出居中黑色磨砂毛玻璃浮层。
   * 超大等宽字体网格排列，每个字符下方显示 **1-based 下标编号**（方便在远程终端/手机上逐位对照输入），同样保留三色区分。
3. **悬浮操作条（Hover-Reveal Field Actions）**
   * 详情页字段行默认极简：左侧标签（小号弱化灰）+ 下方/右侧字段值，绝不堆满按钮。
   * 鼠标悬停或键盘聚焦该字段行时，右侧平滑浮现：`复制`、`显示/隐藏`、`Large Type`、`打开链接`（仅 URL 类型）。点击任意敏感字段值也可直接一键复制。
4. **TOTP 动态验证码**
   * 显示格式强制 `123 456`（中间空格分组）；右侧附带 30 秒倒计时 SVG 环形进度条；
   * 剩余 `<= 5` 秒时进度环与文字平滑变为警戒红并轻微脉冲；点击整行即复制当前 6 位数字。
5. **内嵌式密码生成器（Generator Popover）**
   * 编辑密码字段时点击输入框右侧骰子图标即就地弹出生成器浮层，支持三个 Tab：
     * **随机密码**：长度滑块（8–64）、开关（数字/符号/避免易混淆字符）、实时生成预览 + 强度条；
     * **易记助记词（Memorable）**：单词数（3–8）、分隔符（`-` / `.` / `_` / 空格）、首字母大写/加数字开关；
     * **PIN 码**：4–12 位纯数字。
   * 点击“使用密码”直接回填当前字段，并在保存时将旧密码自动归档进 `passwordHistory`。
6. **安全反馈 Toast**
   * 复制敏感字段后在窗口底部居中弹出胶囊 Toast：`已复制「密码」· 30 秒后自动清空剪贴板`（支持点击“立即清空”）。
7. **Passkey 通行密钥聚合视图与只读凭据卡片**
   * 已绑定或独立保存通行密钥的条目在列表右侧显示天蓝色 `Passkey` 徽章；侧边栏顶部提供「通行密钥」智能聚合筛选。
   * 详情页只读展示 Passkey 凭据信息（依赖方 `rpId`、账户名、ES256 算法、`signCount` 签名次数、最近使用时间、凭据 ID 复制），支持「前往网站管理 ↗」与「移除通行密钥」（提示仅本地移除，需同步前往网站端撤销公钥）；工作台不提供手动创建网站 Passkey 的入口。

### 各栏核心交互规则

* **左栏（Sidebar）**：
  * 顶部 **Vault 切换器**：可在“全部保险库”与单个 Vault 间切换，支持新建/重命名 Vault。
  * **智能入口**：包含 `全部条目`、`收藏`、`通行密钥`（聚合所有已绑定 Passkey 的 `Login` 与独立通行密钥条目）与带实时风险角标的 `Watchtower`。
  * **类别与标签**：类别仅列出 10 种可手动创建的条目类型；点击即时过滤中间栏；支持多标签高亮显示数量。
  * **底部状态栏**：左侧一键锁定（`⌘L`），中间同步旋转状态与最后同步时间，右侧 Quick Access 与偏好设置按钮。
* **中栏（Item List）**：
  * **即时搜索框（`⌘F`）**：输入即响应（< 10ms 内存检索），支持中文拼音首字母与高级语法：`tag:生产`、`vault:工作`、`is:favorite`、`cat:ssh`。
  * **虚拟滚动**：使用 `@tanstack/react-virtual`，即使数千条记录也保持 60fps 滚动。
  * **新建按钮（`⌘N`）**：弹出分类网格选择器，按使用频次排列 10 种内置模板。
* **右栏（Detail / Editor）**：
  * **查看模式 ↔ 编辑模式原地切换**：点击右上角“编辑（`⌘E`）”后，卡片原位变为可编辑表单，避免弹窗割裂感。
  * **编辑态能力**：支持修改标题/图标、切换所属 Vault、增删 Tag 胶囊、新增自定义分组（Section）与自定义字段（可选任意 `FieldType`）、拖拽调整字段顺序、查看并还原“密码历史记录”。

## 4. 引导、锁屏与 Quick Access 浮窗

### 4.1 首次引导 & 锁屏状态

* **登录/注册页**：居中卡片，包含服务器地址（默认预填 `http://localhost:8080` 并提供连通性检测圆点）、邮箱（标注 `autocomplete="username webauthn"` 以支持浏览器 Conditional UI 自动建议）、主密码；切换“注册新账户”Tab 时展示主密码强度实时校验与二次确认；登录页提供 **「使用通行密钥 (Passkey / PRF) 登录」** 快捷入口。
* **锁屏页**：居中头像与邮箱提示 + 主密码输入框 + **Touch ID 快捷解锁按钮**（若已启用）+ **Passkey / 硬件安全密钥解锁按钮**；密码错误时输入框执行轻量横向抖动动画并清空错误输入。

### 4.2 Quick Access 迷你悬浮窗（Phase 2）

* 通过全局快捷键 `⌘⇧Space` 在任意应用之上居中呼出（无标题栏、高圆角磨砂浮窗，宽约 620px）。
* **纯键盘流**：
  * 呼出即自动聚焦搜索框；
  * `↑ / ↓` 移动选中条目；
  * `⏎` 复制密码并自动隐藏浮窗（切回原应用即可 `⌘V` 粘贴）；
  * `⇧⏎` 复制用户名；`⌥⏎` 复制 TOTP；
  * `→` 原地展开右侧迷你预览面板浏览全部字段；
  * `⌘O` 打开完整主窗口并定位到该条目；`Esc` 立即隐藏。

### 4.3 Watchtower 安全体检面板

点击左栏 Watchtower 后，右侧区域展示整体安全评分环（0–100）及可点击的分类卡片（`弱密码`、`重复使用的密码`、`未开启 2FA`、`不安全 HTTP 网站`、`即将过期`、`已泄露密码检测`）。点击任意分类卡片，直接将中间栏过滤为对应风险条目，修复后评分实时回升。

### 4.4 Passkey 被动唤起确认弹窗（扩展/系统触发）与账户通行密钥管理

* **WebAuthn Prompt 弹窗（仅由网站被动唤起，工作台无手动触发入口）**：
  * 仅当浏览器扩展拦截到网页 `navigator.credentials.create` / `get` 或 macOS `ASAuthorizationProviderExtension` 收到系统请求并下发 `passkey:request_prompt` 时自动弹出：
  * **保存确认**：`rpId`、`rpName` 与 `userName` 均由网站请求自动锁定带入（不可手改），智能匹配已有 `Login` 条目合并绑定，或自动创建独立 `Passkey` 条目；
  * **登录确认**：展示匹配当前 `rpId` 的可发现通行密钥，点击确认后完成私钥签名、递增 `signCount` 并回传断言。
* **工作台内的网站 Passkey 管理边界**：
  * 未绑定 Passkey 的 `Login` 条目仅提示“在网站账户设置中添加通行密钥时，Keysmith 扩展或 macOS 自动填充将自动唤起保存”；已绑定 Passkey 的条目仅支持查看元数据、跳转网站管理及本地移除（含前往网站端同步撤销的二次确认）。
* **偏好设置 → 账户通行密钥管理**：唯一允许在设置中主动注册 Passkey 的场景——为 Keysmith / Vaultwarden 自身账户绑定平台 Passkey 或硬件安全密钥（支持 `WebAuthn PRF` 免主密码解锁），展示 AAGUID 提供商图标、`multiDevice`/`singleDevice` 状态、支持重命名/删除与 Signal API 同步。

## 6. 前端工程与状态架构

### 6.1 状态分层（Zustand）

| Store | 职责 | 持久化策略 |
| :--- | :--- | :--- |
| `sessionStore` | `authStatus`（`Unauthenticated`/`Locked`/`Unlocked`）、账户元信息、生物识别状态、自动锁倒计时 | 仅存内存；跟随 `session:state_changed` 事件同步 |
| `vaultStore` | `vaults`、当前筛选结果 `items: ItemSummary[]`、`activeItem: ItemDetail`、同步状态、Watchtower 报告 | 仅存内存；锁定事件触发时立即清空所有状态 |
| `uiStore` | 侧边栏选中维度（Vault / Category / Tag / Watchtower / Trash）、搜索词、排序方式、编辑态标记、主题偏好、Toast 队列 | 仅主题与栏位宽度可存 `localStorage`，业务筛选不落盘敏感词 |

### 6.2 组件与数据流约定

* 所有与 Rust 交互必须收口于 `src/services/tauriClient.ts`，禁止在组件中散落原生 `invoke()` 字符串调用。
* 输入框涉及密码/Secret 必须绑定 `autoComplete="off" autoCorrect="off" autoCapitalize="off" spellCheck={false}`，防止系统级输入法词库或拼写检查缓存明文口令。
* 全局监听 `keydown` / `mousemove` 节流（每 10 秒最多通知一次 `session_touch_activity`），保证空闲自动锁精确而不产生 IPC 噪音。
